# UX copy

Adapted from [content-designer/ux-writing-skill](https://github.com/content-designer/ux-writing-skill) (MIT).
Every string a user reads must clear four standards, in order:

1. **Purposeful** — serves the user's goal (and the product's) at this moment.
2. **Concise** — fewest words that keep the meaning. 40–60 characters per line max.
3. **Conversational** — natural, human, plain language; no jargon.
4. **Clear** — unambiguous, one reading. Aim 7th–8th grade level.

Comprehension drops with length: ≤8 words ≈ 100%, ≤14 words ≈ 90%. Front-load the
critical word.

## Patterns

- **Buttons:** active verb + object — "Save changes", "Open a table", not "OK".
- **Errors:** problem + cause + fix, briefly. Never blame the user.
- **Success:** confirm exactly what happened.
- **Empty states:** explain the absence, then offer the action.
- **Tone:** shift with the user's state (frustrated / confused / confident /
  cautious / successful) while keeping one brand voice.
- **Accessibility:** pair every icon with text; write for screen readers.

## Localization

- Keep terminology consistent within and across languages — one term per concept.
- Translate meaning and tone, not words; match length so layouts don't break.
- Proper nouns and game names stay as-is across languages.
- Keep the same voice in each language: warm, plain, unfussy.

## Process

Edit in four passes — purposeful → concise → conversational → clear — then read it
aloud. If it sounds like a form, rewrite it.
